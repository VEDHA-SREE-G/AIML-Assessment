# Customer Sales Analysis

## Objective

Analyze customer sales transactions using Pandas and Matplotlib. The project cleans missing values, computes revenue by category, identifies top customers, and visualizes monthly sales trends.

## Dataset Columns

* invoice_no
* customer_id
* category
* quantity
* price
* invoice_date
* shopping_mall

## Requirements

Install dependencies:

pip install pandas matplotlib

## How to Run

Run the script:

python Q1.py

## Output Generated

* cleaned_sales.csv
* Monthly Sales Plot
* Revenue by Category Plot
* Summary Statistics
* Top 10 Customers

## Technologies Used

* Python 3.x
* Pandas
* Matplotlib
