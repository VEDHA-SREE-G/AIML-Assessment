# Titanic Survival Prediction

## Objective

The objective of this project is to predict whether a passenger survived the Titanic disaster using machine learning techniques.

## Dataset

The Titanic dataset contains passenger information such as age, gender, passenger class, fare, and family details.

Target Variable:

* survived

  * 0 = Did Not Survive
  * 1 = Survived

## Project Workflow

1. Load the Titanic dataset.
2. Perform Exploratory Data Analysis (EDA).
3. Handle missing values.
4. Engineer new features.
5. Convert categorical data into numerical form.
6. Split data into training and testing sets.
7. Train Logistic Regression and Random Forest models.
8. Compare model performance.
9. Select the best model for deployment.

## Features Used

* pclass
* sex
* age
* fare
* familysize
* embarked
