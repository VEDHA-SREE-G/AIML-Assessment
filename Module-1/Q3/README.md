# Iris Flower Classification using Decision Tree

## Objective

The objective of this project is to build a machine learning model that classifies Iris flowers into three species: Setosa, Versicolor, and Virginica.

## Dataset

The Iris dataset is a built-in dataset provided by scikit-learn.

Features:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

Target Classes:

* Setosa
* Versicolor
* Virginica

## Requirements

Install required libraries:

pip install scikit-learn pandas matplotlib

## How to Run

Run the script:

python Q3.py

## Workflow

1. Load Iris dataset
2. Split dataset into training and testing sets
3. Train a Decision Tree Classifier
4. Make predictions on test data
5. Calculate accuracy
6. Generate confusion matrix

## Output

* Model Accuracy
* Confusion Matrix
* Confusion Matrix Visualization

## Technologies Used

* Python 3.x
* Scikit-learn
* Pandas
* Matplotlib
